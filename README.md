# contabilidade2027

Análise e proposta sobre o que o INEMA pode oferecer à contabilidade com IA. Cobre os escritórios, o contador pessoa física, os serviços que ele vende aos clientes e como escalar o negócio.

- **Proposta:** [PROPOSTA.md](PROPOSTA.md)
- **Fontes:** `fontes/` (2 PDFs + texto extraído; fora do git)

## O processo, do início ao fim

1. 🧠 Receber os PDFs de pesquisa e copiar para `fontes/`: `cp <pdf> fontes/`
2. ⚙️ Extrair o texto: `pdftotext -layout fontes/<x>.pdf fontes/<x>.txt`
3. 🧠 Ler, cruzar com os projetos INEMA vizinhos (contaviral, calculadora-da-reforma, arquiteto-agentes-contabil) e escrever `PROPOSTA.md`
4. 🧠 Validar as dores e os serviços: pesquisa na web + contagem nas transcrições do contaviral (`~/projetos/output/contaviral/coleta/tx/`) → `VALIDACAO.md` *(feito em 24/11)*
5. 🧠 Nei decide o modelo comercial e o primeiro kit *(pendente)*
6. 🧠 Construir o primeiro kit (Diagnóstico Reforma + Caixa) + guia PT/EN/ES *(pendente)*
7. 🧠 Piloto com 3–5 escritórios da comunidade, com métricas *(pendente)*
